# lab3

Практическое задание FoodCampus, мой модуль - CartModule (корзина).
User story: студент кладёт блюда в корзину и применяет промокод для скидки.

Файлы:
- cart_service.py - модуль, метод calculate_total: считает сумму, промокод STUDENT2024 даёт скидку 10%
- test_runner.py - тесты (3 обычных и 4 негативных, негативные это когда специально подаёшь кривые данные)
- bug_report.md - 3 бага, которые нашлись на негативных тестах

Запуск тестов:
python test_runner.py
