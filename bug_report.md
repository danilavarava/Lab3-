# Баг-репорт

Модуль CartModule, метод calculate_total. Негативное тестирование, то есть подача заведомо неверных данных.

| ID | Модуль и метод | Входные данные | Ожидаемый результат | Фактический результат |
|----|----------------|----------------|---------------------|-----------------------|
| BUG-01 | CartModule.calculate_total | список с минусовой ценой: [-500, 100] | ошибка валидации или игнор минусовой цены | ошибки нет, молча вернулся 0.0, деньги просто пропали из чека |
| BUG-02 | CartModule.calculate_total | текст вместо цены: ["борщ", 100] | внятное сообщение, что данные неверные | падает с TypeError, юзеру вообще ничего непонятно |
| BUG-03 | CartModule.calculate_total | промокод маленькими буквами: student2024 | скидка должна работать без учёта регистра | скидка не применилась, студент переплачивает 100 |

Как воспроизвести: запустить python test_runner.py, закрыты тесты 4-6.

Итог: happy path работает, но входные данные модуль не проверяет вообще. Надо добавить валидацию цен и нормализацию промокода (strip + lower).
